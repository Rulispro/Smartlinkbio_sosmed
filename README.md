Ikuti langkah ini di Vercel lewat HP Android:

* Buka Vercel Dashboard  dan login.

* Pilih project kamu, yaitu Smartlinkbio_sosmed.

* Di halaman project, cari tab Settings. Biasanya ada di menu bagian atas. Jika tidak terlihat di HP, coba geser menu ke samping atau aktifkan Situs desktop di Chrome.

* Di menu Settings, cari dan pilih Environment Variables.

    ![Hasura Fit Part Six: Setting Up Vercel | Hygraph](https://images.openai.com/static-rsc-4/l_7X8S4nMiCc137mJqAAbG_zgF7kpRKyrkx9pYZNpuENG4ulf9vVlnQOv9rv6WMfDY1Upo002ZnMLQMxEPJ1QwajXDjjxSLxxLHJQDTKv4Qn8t0yePlB4LHKDXSPaTADYruB6FDvdbwZ34zrsja6JXmMie_v3wW7oyQUJ18Yxxyycxtq-FJpUrC21TsirAuH?purpose=fullsize)

* Tambahkan variabel satu per satu dengan mengisi kolom Key dan Value, lalu klik Save.

Masukkan 5 variabel berikut:

| Key            | Value                        |
| -------------- | ---------------------------- |
| GITHUB_TOKEN   | Token GitHub kamu            |
| GITHUB_OWNER   | Rulispro                     |
| GITHUB_REPO    | Smartlinkbio_sosmed          |
| GITHUB_BRANCH  | main                         |
| ADMIN_PASSWORD | Password rahasia buatan kamu |

Pilih environment Production (dan Preview juga jika ingin menguji deployment Preview).

Setelah semua variabel tersimpan, buka Deployments, pilih deployment terbaru, lalu klik menu `...` dan pilih Redeploy agar variabel baru diterapkan.

Penting: Jangan kirim `GITHUB_TOKEN` atau password admin ke chat maupun screenshot.
